# Frontend and UI work

For frontend and UI tasks, use the relevant installed skills together:

- `frontend-design` for visual direction and aesthetics.
- `ui-ux-pro-max` for design systems and UX decisions.
- `frontend-ui-engineering` for production quality, accessible implementation.
- `motion-site-builder` for advanced animation and interaction work.
- `web-design-guidelines` for web interface quality and consistency checks.

Before implementing a UI, inspect the project architecture, establish a consistent design language, plan layout, typography, colors, spacing, and interactions, then implement without breaking existing functionality. Review the result for visual consistency, responsive behavior, accessibility, and animation smoothness.

Preferred aesthetic: premium Apple inspired design that feels minimal, sophisticated, fluid, intuitive, and visually polished. Avoid generic layouts, excessive gradients, unnecessary glass effects, and decorative animations that reduce usability.
